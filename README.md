# 💰 Controle Financeiro em Python

Sistema de controle financeiro desenvolvido em Python para gerenciamento de entradas, gastos e acompanhamento da vida financeira.

## 🚀 Funcionalidades

- 🟢 Adicionar entradas
- 🔴 Registrar gastos
- 💰 Consultar saldo
- 📋 Visualizar histórico de transações
- 📊 Calcular resumo financeiro
- 🗂️ Resumo de gastos por categoria
- 🔎 Pesquisar transações
- ✏️ Editar transações
- 🗑️ Excluir transações
- 💾 Salvar e carregar dados automaticamente utilizando JSON
- ✅ Validação de valores e entradas do usuário

## 🛠️ Tecnologias utilizadas

- Python
- JSON
- Git
- GitHub
